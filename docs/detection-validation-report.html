01 Executive summary

A single simulated adversary — a ransomware affiliate — was played end to end against the tenant cushioning.onmicrosoft.com and its on-prem CORP domain: from an adversary-in-the-middle phish of a finance user, through defence evasion and credential theft, to Pass-the-Hash lateral movement and a PsExec-style ransomware service push onto a file server. The telemetry was written into nine Microsoft Defender / Entra tables and diluted with realistic benign traffic so that each analytic had to find the attack rather than simply return the only rows present.

All 16 hunts detected their stage of the intrusion and ranked it above the background. Two hunts — HL-003 and HL-015 — were found to contain an invalid KQL operator that made them fail to run at all; both are now fixed and verified. One hunt, HL-013, carries a placeholder domain list that must be tuned to the real environment before it will match.

05 Defects found & fixed

Running the analytics — rather than eyeballing them — exposed two that could not execute in KQL at all. Both are corrected on branch claude/kusto-mcp-integration (commit f3e09c6) and re-verified above.

HL-003 · LSASS credential accessFIXED

Two issues in one clause: has_any was applied to a tolong() value (it requires a string), and & was used as a bitwise-AND operator — which KQL does not have. The query raised Syntax error: Expected: ) and never ran.

- | where AccessRights has_any ("0x1fffff","0x1010",…) or (AccessRights & 16) != 0
+ | where AccessRightsHex has_any ("0x1fffff","0x1010",…) or binary_and(AccessRights, 16) != 0
HL-015 · EDR process terminationFIXED

The Arm-2 terminate-rights test used the same non-existent & operator, so the whole three-arm union failed to compile.

- or (AccessRightsNum & 1) != 0
+ or binary_and(AccessRightsNum, 1) != 0
Tuning note — HL-013. The Pass-the-Hash hunt ships with a placeholder domain allow-list ("domain1","domain2","domain3"). On real data it returns nothing until tuned to the environment's NetBIOS domains; it was run here tuned to corp. Worth flagging in the hunt's curator notes as a required deployment step.
